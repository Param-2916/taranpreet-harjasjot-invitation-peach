PEACH-THEMED PUNJABI WEDDING INVITATION

Keep index.html, style.css, app.js, config.js, i18n.js, and assets/ together.
This is a dependency-free static website; it has no backend or database requirement.

The invitation wording in index.html is transcribed from "Taranpreet weds Harjasjot.pdf".
The PDF is a source reference and is not loaded by the website.

To replace the soundtrack, update CONFIG.assets.song in config.js and place the
audio file at that path. Music begins only after the guest opens the invitation.
If the browser cannot play the supplied file, a gentle generated audio placeholder
is used and the music control remains available.

The retained T&H monogram is assets/monogram.PNG. Keep the filename case unchanged
on case-sensitive hosting.
